# Cheats for BOTW 1.8.2

Use the original game files in Recompiled Mode. Updating the app requires rebuilding the game code once. Remove any previously patched copy of exefs/main from the setup source before rebuilding.

Import either directory below with Mods > Import a mod folder. The existing mod switches apply on the next game start. A marker only selects a built-in patch for this specific build. Its contents are ignored and the file is excluded from the RomFS overlay.
